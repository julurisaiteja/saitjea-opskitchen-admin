# OpsKitchen Admin

Multi-restaurant kitchen operations — dense dark data maximal dashboard.

## Run locally

```bash
npm i
npm run dev
```

Open http://localhost:3000

```bash
npm run build
```

Diamond admin ops UI. No product-3D gimmicks.
